# Hand Gesture Recognition using ESP32 and Python

## Overview
This project implements a real-time hand gesture recognition system using Python, OpenCV, MediaPipe, and ESP32. The detected gestures are transmitted over Wi-Fi using HTTP requests to control LEDs connected to the ESP32.
